# Start working on Raahi

The shared repository is [ParmiGohil/Raahi](https://github.com/ParmiGohil/Raahi), with default branch `main`. It contains the project plan and research for a two-person team. Application implementation has not started.

## Join in five minutes

1. Clone Raahi, or pull the latest `main` if you already have a clone.
2. Open your clone as a local project in Codex.
3. Start a task using [TEAMMATE_START_PROMPT.txt](TEAMMATE_START_PROMPT.txt).
4. Assign an engine owner, a UI owner, and one integrator.
5. Let one person establish the scaffold and shared contract, then continue on separate feature branches.

Git synchronizes code and shared documents between your machines. Your Codex tasks keep their own conversations; these documents supply the common context.

- Use code to determine feasibility, costs and state changes.

- Cash needed now is separate from future refunds.
- Applying a prototype plan does not confirm supplier transactions.
